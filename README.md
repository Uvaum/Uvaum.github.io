# Rhuan Oliveira · Portfólio

Portfólio pessoal de desenvolvedor Full Stack — Python · Django · React · AWS.

🔗 **https://uvaum.github.io**

## Stack

- React 19 + TypeScript + Vite
- Framer Motion (animações, scroll reveal, cards 3D)
- Conteúdo bilíngue (PT/EN)
- Repositórios carregados ao vivo pela API do GitHub
- Deploy automático no GitHub Pages via GitHub Actions

## Rodando localmente

```bash
npm install
npm run dev
```

## Editando o conteúdo

Todos os textos ficam em [`src/data/content.ts`](src/data/content.ts).
Para usar sua foto, coloque um arquivo `public/foto.jpg`.
